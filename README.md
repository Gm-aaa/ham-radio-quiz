# 业余无线电刷题

基于 **CRAC 2025 版**业余无线电台操作技术能力验证题库的在线刷题页面，纯静态、无框架、无需构建，可直接部署到 GitHub Pages。

在线使用：<https://gm-aaa.github.io/ham-radio-quiz/>

## 功能

- **A / B / C 类分类筛选**：按报考类别过滤题目（A 类 683 题 / B 类 1143 题 / C 类 1282 题，共 1375 题）
- **章节练习**：按题库章节（含中文标题）分组刷题
- **顺序练习 / 随机模考 / 错题本**三种模式
  - 随机模考抽 50 题，答对 38 题及以上判为通过
  - 错题自动收录（localStorage 本地保存），可随时只刷错题
- **选项乱序**：每次渲染题目时选项内容随机打乱（字母 A–D 位置固定），与正式考试选项随机打乱的习惯一致，避免死记字母位置
- **答题即判 + 文字解析**：单选点击即判，多选需确认提交；作答后以文字显示正确答案，并附每题解析
- **明暗主题切换**

## 题库来源

- [CRAC 官方题库发布页](https://www.crac.org.cn/?p=1287)
- [知乎题库整理文章](https://zhuanlan.zhihu.com/p/2012845316643251467)

题目数据由 `extract.py` 从官方 PDF 提取，并与 A / B / C 三类题库交叉比对得出每题所属分类。每题解析为 AI 辅助编写，力求通俗易懂；法规题交代立法背景，计算题讲解原理。如发现解析有误，欢迎提 Issue 或 PR。

## 关于更新（重要）

业余无线电操作技术能力验证题库大约**每四年更新一次**，更新频率很低，因此本项目的维护节奏也会比较慢：

- 当前数据基于 **2025 版**题库；
- 在下一版题库（预计 2029 年前后）发布之前，题目内容一般不会有实质变化，本页面通常无需更新；
- 新版题库发布后，会重新跑一遍提取脚本更新数据，但响应可能不会很及时，请耐心等待。

## 项目结构

```
ham-radio-quiz/
├── index.html          # 主页面
├── app.js              # 答题逻辑
├── style.css           # 样式（含明暗主题）
├── extract.py          # PDF 题库提取脚本
└── data/
    └── questions.json  # 全部 1375 题（含解析与分类）
```

## 本地运行

纯静态页面，任选一种方式起一个本地服务即可：

```bash
cd ham-radio-quiz
python3 -m http.server 8000
# 或 npx serve .
```

打开 <http://localhost:8000> 即可刷题。
